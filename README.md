# Heart Disease Risk Prediction

Hasta verileri üzerinden makine öğrenmesi ile kalp hastalığı riskini tahmin eden bir sınıflandırma projesi. Veri ön işleme, özellik mühendisliği ve model değerlendirme adımlarını içerir.

**Kullanılan teknolojiler:** Python, Pandas, NumPy, Scikit-learn, matplotlib, seaborn

**Sonuç:** 
- Lojistik Regresyon: %85
- SVM (RBF): %81
- KNN: %79
- Random Forest: %83
